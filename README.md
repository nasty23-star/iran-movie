# Иранское кино

Telegram mini app с каталогом иранского кино. Vue 3, TypeScript и Vite.

При открытии приложение здоровается по имени Telegram-аккаунта. Вне Telegram имя — «Гость». Дальше короткая справка, почему смотреть именно иранское кино. Кнопка «Пропустить» открывает каталог и больше не показывает справку при следующем запуске.

На широком экране разделы слева: главная, номинации на Оскар, мой топ фильмов, рандом, избранное. На узком — те же разделы в нижней панели. У избранного виден счётчик. Со страниц кроме главной есть «На главную». Внутри Telegram вместо неё работает системная кнопка «Назад».

## Что внутри

- Каталог: поиск по названию, период, режиссёр, жанр и «Скрыть просмотренное». Заданные условия пишутся в адрес (`q`, `from`, `to`, `director`, `genre`, `hide=1`) и остаются после обновления и возврата со страницы фильма. «Сбросить фильтры» очищает их. Над выдачей — «Фильмов: N» и «Смотрели N из M».
- Карточка в выдаче: постер, название, год, режиссёр, рейтинг IMDb и избранное. Название открывает страницу фильма. «Показать описание» раскрывает текст, «Просмотрено», «В чёрный список» и ссылку на IMDb. Если фильм уже смотрели или он в чёрном списке, это видно и на свёрнутой карточке.
- Страница фильма: постер, название, год, режиссёр, жанры, описание, заметка Оскара, если она есть, ссылка на IMDb, избранное, «смотрел», чёрный список и «Поделиться». Ниже до шести похожих: сначала тот же режиссёр, затем общие жанры. Неизвестный id показывает «Фильм не найден».
- Рандом выбирает один фильм из каталога. Шанс выше у того, что ближе к избранному по режиссёру и жанру. Просмотренное и чёрный список не участвуют, подряд один и тот же фильм не выпадает. На странице можно отметить текущий фильм и снять отметку со списков.
- Избранное: заметка до 200 символов на фильм, её же можно править на странице фильма. «удалить» убирает фильм и оставляет «Вернуть», пока не сделано следующее действие: возврат восстанавливает и заметку. Весь список экспортируется в Telegram. При успехе — «список успешно экспортирован». «Поделиться» на странице фильма отправляет одну карточку.
- Светлая и тёмная темы. Выбор сохраняется.

Списки живут в `localStorage`. Внутри Telegram тот же снимок синхронизируется через CloudStorage: при старте побеждает более новая метка времени, ошибка облака экран не блокирует. Вне Telegram остаётся только локальное хранилище.

Каталог лежит в `src/data/catalog.json`. «Мои рекомендации» — отдельный файл `src/data/recommendations.json`, он открывается как «мой топ фильмов».

## Стек

Vue 3 (Composition API, `<script setup>`), TypeScript, Vite, Vue Router, Tailwind CSS, oxlint, oxfmt.

Практики проекта — в `skills.md`.

## Запуск

Нужен Node.js 22+.

```bash
pnpm install
pnpm run dev
```

Сервер слушает [http://127.0.0.1:5173/iran-movie/](http://127.0.0.1:5173/iran-movie/). Хост задан явно: на Windows Vite иначе поднимается только на IPv6.

Сборка и предпросмотр:

```bash
pnpm run build
pnpm run preview
```

Роутер на hash (`/iran-movie/#/oscar`), поэтому собранное приложение открывается с обычной статики, без fallback на `index.html`.

## Скрипты

| Команда              | Что делает                                    |
| -------------------- | --------------------------------------------- |
| `pnpm run dev`       | Dev-сервер                                    |
| `pnpm run build`     | Проверка типов (`vue-tsc -b`) и сборка        |
| `pnpm run preview`   | Просмотр сборки                               |
| `pnpm run lint`      | oxlint                                        |
| `pnpm run fmt`       | oxfmt, записать формат                        |
| `pnpm run fmt:check` | Проверить формат без записи                   |
| `pnpm run posters`   | Заново собрать SVG-постеры в `public/posters` |

## Структура

```
src/views        экраны
src/layouts      оболочка с сайдбаром
src/components   карточки, фильтры, тема
src/composables  каталог, фильтры, избранное, списки, тема, Telegram
src/data         catalog.json и recommendations.json
src/router       маршруты
```

Ключи `localStorage`: `iran-cinema-favorites`, `iran-cinema-favorite-notes`, `iran-cinema-watched`, `iran-cinema-blacklist`, `iran-cinema-intro-seen`, `iran-cinema-theme`. Тот же ключ темы читает скрипт в `index.html`, чтобы не мигала светлая тема до запуска Vue. Старый список id без метки времени при чтении становится снимком и может уехать в облако.

Внутри Telegram имя берётся из `Telegram.WebApp.initDataUnsafe.user`. Экспорт списка и одного фильма идёт через `openTelegramLink`. Вне Telegram открывается окно `https://t.me/share/url`, откуда текст можно отправить в «Избранное».
