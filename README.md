# Иранское кино

Telegram mini app с каталогом иранского кино. Vue 3, TypeScript и Vite.

При открытии приложение здоровается по имени Telegram-аккаунта. Вне Telegram имя — «Гость». Дальше короткая справка, почему смотреть именно иранское кино. Кнопка «Пропустить» открывает каталог.

## Что внутри

- Каталог: поиск по названию, фильтры по году, режиссёру и жанру, кнопка «Сбросить фильтры».
- Карточка в выдаче: постер, название, год, рейтинг IMDb и ссылка на фильм.
- Слева категории: номинации на Оскар, мой топ фильмов, избранное. С этих страниц есть возврат на главную.
- Фильм можно сохранить в избранное. На странице избранного список удаляется кнопкой «удалить», весь список экспортируется в Telegram. При успехе показывается текст «список успешно экспортирован».
- Светлая и тёмная темы. Выбор сохраняется.

Каталог лежит в `src/data/catalog.json`. «Мои рекомендации» — отдельный файл `src/data/recommendations.json`, он открывается как «мой топ фильмов».

## Стек

Vue 3 (Composition API, `<script setup>`), TypeScript, Vite, Vue Router, Tailwind CSS, oxlint, oxfmt.

Практики проекта — в `skills.md`.

## Запуск

Нужен Node.js 22+.

```bash
pnpm install
pnpm run dev
```

Сервер слушает [http://127.0.0.1:5173/](http://127.0.0.1:5173/). Хост задан явно: на Windows Vite иначе поднимается только на IPv6.

Сборка и предпросмотр:

```bash
pnpm run build
pnpm run preview
```

Роутер на hash (`/#/oscar`), поэтому собранное приложение открывается с обычной статики, без fallback на `index.html`.

## Скрипты

| Команда              | Что делает                                    |
| -------------------- | --------------------------------------------- |
| `pnpm run dev`       | Dev-сервер                                    |
| `pnpm run build`     | Проверка типов (`vue-tsc -b`) и сборка        |
| `pnpm run preview`   | Просмотр сборки                               |
| `pnpm run lint`      | oxlint                                        |
| `pnpm run fmt`       | oxfmt, записать формат                        |
| `pnpm run fmt:check` | Проверить формат без записи                   |
| `pnpm run posters`   | Заново собрать SVG-постеры в `public/posters` |

## Структура

```
src/views        экраны
src/layouts      оболочка с сайдбаром
src/components   карточки, фильтры, тема
src/composables  каталог, избранное, тема, Telegram
src/data         catalog.json и recommendations.json
src/router       маршруты
```

Избранное хранится в `localStorage` под ключом `iran-cinema-favorites`. Тема — `iran-cinema-theme`. Тот же ключ темы читает скрипт в `index.html`, чтобы не мигала светлая тема до запуска Vue.

Внутри Telegram имя берётся из `Telegram.WebApp.initDataUnsafe.user`. Экспорт списка идёт через `openTelegramLink`. Вне Telegram открывается окно `https://t.me/share/url`, откуда список можно отправить в «Избранное».
